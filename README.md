# Plant Disease Detection Using Machine Learning

## About
This project detects plant diseases using machine learning.

## Technologies Used
- Python
- TensorFlow
- NumPy
- PIL

## Project Files
- train.py – Train the machine learning model
- predict.py – Predict plant disease
- dataset – Plant disease dataset
- requirements.txt – Required Python libraries

## How to Run

Install the required libraries:

pip install -r requirements.txt

Train the model:

python train.py

Run prediction:

python predict.py
